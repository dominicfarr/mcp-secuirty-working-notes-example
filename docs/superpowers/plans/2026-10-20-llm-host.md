# LLM host (Part 2, sub-project 3) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** a Chat tab in which a model calls the server's tools through the Part 1 client, so every
model call meets the same policy, approval, audit and server checks.

**Architecture:** `model.py` wraps any OpenAI-compatible endpoint behind a one-method protocol;
`agent.py` runs a turn as a state machine over `request_tool` / `approve` / `reject` /
`answer_input`; `host.py` subclasses the Part 1 app and adds the Chat tab. The client gains a
`source` on each request; the server gains a `workspace://` resource template.

**Tech stack:** Python 3.13, mcp 2.3.0, fastmcp 4.1.1, gradio 6.30.0, openai 2.6.1, pytest.

**Spec:** docs/superpowers/specs/2026-10-20-llm-host-design.md

## Global constraints

- No commits, no staging (the user commits). Never touch port 7863 or the user's processes;
  kill only PIDs started here. Browser checks use port 7899.
- Baseline only: no LLM-specific defences (no labelling of tool results, no hiding of denied
  tools, no description sanitising).
- `TOOL_ROUNDS_MAX = 8`. Model defaults: `HOST_MODEL_BASE_URL=http://localhost:11434/v1`,
  `HOST_MODEL=qwen2.5:7b`, `HOST_MODEL_API_KEY=ollama`. Host port 7864.
- Exact model-facing strings: `Denied by client policy`, `Rejected by the user`,
  `Error: unknown tool <name>`, `Error: arguments were not valid JSON`,
  `Error: the server's question was closed before it was answered`,
  `(stopped after 8 tool rounds)`; busy: `answer or reject the pending request first`.
- System prompt: `You help the user work with files in their workspace using the tools provided.`
- `app.py` imports nothing LLM-related. Server text in the GUI stays a code span (`server_text`).
- Docs move with code: README, spec, plan (memory `keep-docs-in-sync`).
- Run tests with `mcp_security_env/bin/python -m pytest`; lint with
  `(cd client && ../mcp_security_env/bin/python -m pylint --rcfile=../.pylintrc ./*.py)`.

## Review focus

1. **A question from the server leaks into the model's context through a side door**: the chat
   step lines, an error string, or `ToolOutcome.inputs` copied into a tool result. Expected:
   nothing the server asked and nothing the user answered ever reaches `model.complete`.
   (Pinned by `test_server_question_goes_to_the_user_not_the_model`, which searches every
   context sent, and sabotage 1.)
2. **The Tools tab and the Chat tab act on the same pending request** (approve in one, then the
   other). Expected: the second gets a clear "not pending" message, nothing runs twice, and New
   chat still clears the agent. Test added in Task 5: `test_approval_taken_elsewhere_is_reported`.
3. **The model asks for several tools in one reply and the first pauses.** Expected: the rest
   wait, in order, and each gets exactly one tool message (an OpenAI-compatible endpoint rejects
   a context with a missing tool result). Test in Task 4:
   `test_several_calls_in_one_reply_run_in_order_and_each_is_answered`.
4. **The model endpoint is unreachable at startup** (no Ollama running). Expected: the host still
   opens; the Chat tab shows a model error per turn; Part 1 tabs work. Test in Task 5:
   `test_host_opens_without_a_model`.
5. **A huge or non-text resource is attached.** Expected: text contents only, verbatim; binary
   contents are skipped with a note, never decoded into the context. Test in Task 4:
   `test_attached_resource_is_in_context` covers text; binary is handled by `resource_text`
   (Task 4 code) and noted for the reviewer.

```python
def read_text_file(filepath: str) -> str:
    """A UTF-8 text file inside the allowed folder. Raises ToolError with a readable reason."""
    file_path = resolve_allowed(filepath)
    try:
        return file_path.read_text(encoding="utf-8")
    except FileNotFoundError as e:
        raise ToolError(f"File {filepath} not found") from e
    except UnicodeDecodeError as e:
        raise ToolError(f"Error reading file {filepath}: not valid UTF-8 text") from e
    except OSError as e:
        raise ToolError(f"Error reading file {filepath}: {e.strerror}") from e
```

```python
"""The model behind the host: any OpenAI-compatible chat-completions endpoint.

Local Ollama by default; OpenAI, or Anthropic's OpenAI-compatible endpoint, by changing
HOST_MODEL_BASE_URL, HOST_MODEL and HOST_MODEL_API_KEY. Nothing here decides what a tool call
may do: that is the client's job."""

import os
from dataclasses import dataclass
from typing import Protocol

from openai import AsyncOpenAI

DEFAULT_BASE_URL = "http://localhost:11434/v1"  # Ollama's OpenAI-compatible API
DEFAULT_MODEL = "qwen2.5:7b"
DEFAULT_API_KEY = "ollama"  # Ollama ignores it; the SDK requires one


@dataclass(frozen=True)
class ToolCall:
    """One tool call as the model wrote it; the arguments are unparsed JSON text."""
    id: str
    name: str
    arguments_json: str


@dataclass(frozen=True)
class AssistantMessage:
    """The model's reply: text, tool calls, or both."""
    text: str = ""
    tool_calls: tuple[ToolCall, ...] = ()


class ChatModel(Protocol):  # pylint: disable=too-few-public-methods
    """What the agent needs from a model."""
    name: str

    async def complete(self, messages: list[dict], tools: list[dict]) -> AssistantMessage:
        """The model's next reply to the conversation so far, given these tools."""


def tool_specs(tools) -> list[dict]:
    """MCP tools as OpenAI function specs: name, description and input schema exactly as the
    server sent them (the baseline passes server text to the model unchanged)."""
    return [{"type": "function",
             "function": {"name": tool.name, "description": tool.description or "",
                          "parameters": tool.input_schema}}
            for tool in tools]


class OpenAICompatibleModel:  # pylint: disable=too-few-public-methods
    """A chat-completions model reached through the openai SDK."""

    def __init__(self, base_url: str | None = None, model: str | None = None,
                 api_key: str | None = None, client=None):
        self.name = model or os.environ.get("HOST_MODEL", DEFAULT_MODEL)
        self.base_url = base_url or os.environ.get("HOST_MODEL_BASE_URL", DEFAULT_BASE_URL)
        self._client = client or AsyncOpenAI(
            base_url=self.base_url,
            api_key=api_key or os.environ.get("HOST_MODEL_API_KEY", DEFAULT_API_KEY))
        if client is None:
            self.base_url = self._client.base_url

    async def complete(self, messages: list[dict], tools: list[dict]) -> AssistantMessage:
        """One chat completion; tools are sent only if there are any."""
        extra = {"tools": tools} if tools else {}
        response = await self._client.chat.completions.create(model=self.name,
                                                              messages=messages, **extra)
        message = response.choices[0].message
        calls = tuple(ToolCall(call.id, call.function.name, call.function.arguments or "")
                      for call in message.tool_calls or [])
        return AssistantMessage(message.content or "", calls)
```

```python
class ScriptedModel:
    """Stands in for the LLM: returns pre-written replies in order (an exception is raised) and
    records a copy of every context it was sent, so tests can check what the model saw."""
    name = "scripted"

    def __init__(self, *replies):
        self.replies, self.sent, self.tools_sent = list(replies), [], []

    async def complete(self, messages, tools):
        self.sent.append(copy.deepcopy(messages))
        self.tools_sent.append(tools)
        if not self.replies:
            raise RuntimeError("the script has no more replies")
        reply = self.replies.pop(0)
        if isinstance(reply, Exception):
            raise reply
        return reply


def says(text):
    """A scripted reply with text only."""
    from model import AssistantMessage  # pylint: disable=import-outside-toplevel
    return AssistantMessage(text=text)


def calls(name, arguments, call_id="c1"):
    """A scripted reply that calls one tool; arguments as a dict, or raw text to send as is."""
    from model import AssistantMessage, ToolCall  # pylint: disable=import-outside-toplevel
    text = arguments if isinstance(arguments, str) else json.dumps(arguments)
    return AssistantMessage(tool_calls=(ToolCall(call_id, name, text),))
```

```python
"""The host's turn loop: a model calls tools, and every call goes through the client.

This is Part 2's baseline: Part 1's controls only. The model sees every tool (denied ones too),
tool descriptions and results reach it verbatim, and resources and prompts enter its context
only when the user picks them. The server's questions go to the user and never into the model's
context: the model sees only each call's final result."""

import contextlib
import json
from dataclasses import dataclass

from client import InputInvalid, MCPPermissionClient, ToolOutcome
from model import AssistantMessage, ChatModel, ToolCall, tool_specs

SYSTEM_PROMPT = "You help the user work with files in their workspace using the tools provided."
TOOL_ROUNDS_MAX = 8  # robustness (cost, runaway loops), not a defence
DENIED = "Denied by client policy"
REJECTED = "Rejected by the user"
BUSY = "answer or reject the pending request first"
QUESTION_CLOSED = "Error: the server's question was closed before it was answered"
STOPPED = f"(stopped after {TOOL_ROUNDS_MAX} tool rounds)"
WAITING_APPROVAL = "waiting for your approval"
WAITING_ANSWER = "the server is asking you a question"


@dataclass
class TurnResult:
    """Where a turn stands: finished with a reply, paused on the user, or failed."""
    reply: str = ""
    paused: ToolOutcome | None = None  # an approval (decision ASK) or a server question
    error: str = ""


@dataclass(frozen=True)
class Step:
    """One tool call as the chat shows it: what the model asked for and what came of it."""
    tool: str
    arguments_json: str
    result: str


def result_text(outcome: ToolOutcome) -> str:
    """What a finished call gives the model: the server's text, verbatim (an error prefixed)."""
    text = "\n".join(block.text for block in outcome.content or [] if hasattr(block, "text"))
    return f"Error: {text}" if outcome.is_error else text


def resource_text(uri: str, contents) -> str:
    """An attached resource as it joins the user's message: its text, verbatim. Binary
    contents are never decoded into the context."""
    parts = [c.text if hasattr(c, "text") else f"[binary content from {uri} not included]"
             for c in contents]
    return f"Attached resource {uri}:\n" + "\n".join(parts)


def assistant_entry(reply: AssistantMessage) -> dict:
    """The model's reply as a chat-completions message."""
    entry = {"role": "assistant", "content": reply.text}
    if reply.tool_calls:
        entry["tool_calls"] = [{"id": c.id, "type": "function",
                                "function": {"name": c.name, "arguments": c.arguments_json}}
                               for c in reply.tool_calls]
    return entry


class Agent:
    """One conversation between the user, a model, and the server's tools."""

    def __init__(self, client: MCPPermissionClient, model: ChatModel):
        self.client, self.model = client, model
        self.messages: list[dict] = [{"role": "system", "content": SYSTEM_PROMPT}]
        self.paused: ToolOutcome | None = None
        self._queue: list[ToolCall] = []  # the current reply's tool calls not yet answered
        self._rounds = 0
        self._attachments: list[str] = []
        self._tool_names: set[str] = set()
        self._steps: list[Step] = []

    async def send(self, text: str) -> TurnResult:
        """The user's message (with anything attached) starts a turn."""
        if self.paused is not None:
            return TurnResult(error=BUSY)
        content = "\n\n".join([*self._attachments, text])
        self._attachments = []
        self.messages.append({"role": "user", "content": content})
        return await self._start()

    async def use_prompt(self, name: str, arguments: dict) -> TurnResult:
        """A server prompt the user picked: its messages join the conversation with their
        declared roles, and the model replies."""
        if self.paused is not None:
            return TurnResult(error=BUSY)
        for message in await self.client.get_prompt(name, arguments):
            text = getattr(message.content, "text", "")
            self.messages.append({"role": message.role, "content": text})
        return await self._start()

    async def attach_resource(self, uri: str) -> str:
        """Read a resource the user chose; it joins their next message. Returns what was
        attached. Raises (and attaches nothing) if the server refuses."""
        attached = resource_text(uri, await self.client.read_resource(uri))
        self._attachments.append(attached)
        return attached

    async def approve(self) -> TurnResult:
        """The user approved the paused call: the client sends its stored copy."""
        outcome = self._paused_on(question=False)
        return await self._resume(self._settle(await self.client.approve(
            outcome.request.request_id)))

    async def reject(self) -> TurnResult:
        """The user rejected the paused call: nothing is sent, and the model is told."""
        outcome = self._paused_on(question=False)
        self.client.reject(outcome.request.request_id)
        self.paused = None
        return await self._resume(REJECTED)

    async def answer(self, action: str, content: dict | None = None) -> TurnResult:
        """The user answered the server's question. InputInvalid leaves it open."""
        outcome = self._paused_on(question=True)
        try:
            resumed = await self.client.answer_input(outcome.input_request.input_id, action,
                                                     content)
        except KeyError:  # closed meanwhile: timed out, or the server restarted
            self.paused = None
            return await self._resume(QUESTION_CLOSED)
        return await self._resume(self._settle(resumed))

    async def new_chat(self):
        """Start over. A paused approval is rejected and a paused question cancelled, both
        audited by the client."""
        paused, self.paused = self.paused, None
        if paused is not None and paused.input_request is None:
            with contextlib.suppress(KeyError):
                self.client.reject(paused.request.request_id)
        elif paused is not None:
            with contextlib.suppress(KeyError, InputInvalid):
                await self.client.answer_input(paused.input_request.input_id, "cancel")
        self.messages = self.messages[:1]
        self._queue, self._attachments, self._rounds = [], [], 0

    def drain_steps(self) -> list[Step]:
        """The tool steps since the last call, for the chat to show."""
        steps, self._steps = self._steps, []
        return steps

    async def _start(self) -> TurnResult:
        self._rounds = 0
        return await self._run()

    async def _run(self) -> TurnResult:
        """Answer queued tool calls, then ask the model, until it replies with text, the user
        is needed, or the round cap is reached."""
        while True:
            while self._queue:
                result = await self._dispatch(self._queue[0])
                if result is None:
                    return TurnResult(paused=self.paused)
                self._answer_call(result)
            if self._rounds >= TOOL_ROUNDS_MAX:
                return TurnResult(reply=STOPPED)
            try:
                tools = tool_specs(await self.client.list_tools())
                self._tool_names = {spec["function"]["name"] for spec in tools}
                reply = await self.model.complete(self.messages, tools)
            except Exception as e:  # pylint: disable=broad-exception-caught
                return TurnResult(error=f"Model error: {e}")
            self.messages.append(assistant_entry(reply))
            if not reply.tool_calls:
                return TurnResult(reply=reply.text)
            self._rounds += 1
            self._queue = list(reply.tool_calls)

    async def _dispatch(self, call: ToolCall) -> str | None:
        """Send one tool call through the client. Returns the model's tool result, or None
        when the call is paused on the user."""
        if call.name not in self._tool_names:
            self.client.record_not_sent("(unknown tool)", {"name": call.name},
                                        f"unknown tool {call.name}", "model")
            return f"Error: unknown tool {call.name}"
        try:
            arguments = json.loads(call.arguments_json or "{}")
        except json.JSONDecodeError:
            arguments = None
        if not isinstance(arguments, dict):
            self.client.record_not_sent(call.name, {}, "arguments were not valid JSON", "model")
            return "Error: arguments were not valid JSON"
        return self._settle(await self.client.request_tool(call.name, arguments,
                                                           source="model"))

    def _settle(self, outcome: ToolOutcome) -> str | None:
        """The model's tool result for an outcome, or None (and paused) if the user is
        needed."""
        self.paused = None  # e.g. an approval the policy now denies is no longer paused
        if outcome.decision == "DENIED":
            return DENIED
        if outcome.decision == "REJECTED":
            return REJECTED
        if outcome.decision == "ASK" or outcome.input_request is not None:
            self.paused = outcome
            waiting = WAITING_ANSWER if outcome.input_request else WAITING_APPROVAL
            self._steps.append(Step(self._queue[0].name, self._queue[0].arguments_json, waiting))
            return None
        return result_text(outcome)

    async def _resume(self, result: str | None) -> TurnResult:
        if result is None:
            return TurnResult(paused=self.paused)
        self._answer_call(result)
        return await self._run()

    def _answer_call(self, result: str):
        """Give the first queued call its tool result."""
        call = self._queue.pop(0)
        self._steps.append(Step(call.name, call.arguments_json, result))
        self.messages.append({"role": "tool", "tool_call_id": call.id, "content": result})

    def _paused_on(self, question: bool) -> ToolOutcome:
        if self.paused is None or (self.paused.input_request is not None) != question:
            raise RuntimeError("nothing is waiting for that")
        return self.paused
```

```python
"""Part 2 host: the Part 1 app plus a Chat tab in which a model calls the server's tools.

Every call the model makes goes through the same client as the Tools tab: policy, approval,
audit, and the server's questions to the user. This is the baseline for Part 2's attacks: no
LLM-specific defences yet (see README "Part 2: model in the loop")."""

import sys

import gradio as gr
from mcp.shared.exceptions import MCPError

from agent import Agent, Step, TurnResult
from app import LAUNCH_SETTINGS, MCPPermissionClientApp, flow_outputs
from client import InputInvalid
from model import ChatModel, OpenAICompatibleModel
from tools_view import parse_arguments, server_text

# Beside the Part 1 app (7863), not instead of it
HOST_LAUNCH_SETTINGS = {**LAUNCH_SETTINGS, "server_port": 7864}
STEP_RESULT_CHARS = 120  # a step line shows the start of a result; the model gets all of it


def step_line(step: Step) -> str:
    """A tool step for the chat. Arguments and results are model and server text: code spans,
    never links."""
    result = step.result.splitlines()[0][:STEP_RESULT_CHARS] if step.result else "(empty)"
    return f"🔧 model called `{step.tool}` {server_text(step.arguments_json)} → {server_text(result)}"


class MCPPermissionHostApp(MCPPermissionClientApp):
    """The Part 1 app, plus a chat with a model that uses the same client."""
    APP_TITLE = "MCP Host (Part 2: model in the loop)"

    def __init__(self, server_script: str, model: ChatModel | None = None):
        super().__init__(server_script)
        self.model = model or OpenAICompatibleModel()
        self.agent = Agent(self, self.model)
        self.chat: list[dict] = []

    def _tabs(self) -> list:
        return [("Chat", self._build_chat_tab), *super()._tabs()]

    def _chat_outputs(self, result: TurnResult | None = None, status: str = ""):
        """The 10 chat-flow outputs: conversation, status, then the approval card and the
        question card exactly as the Tools tab shows them."""
        self.chat.extend({"role": "assistant", "content": step_line(step)}
                         for step in self.agent.drain_steps())
        if result is not None and result.reply:
            self.chat.append({"role": "assistant", "content": result.reply})
        if result is not None and result.error:
            status = f"⚠ {result.error}"
        paused = self.agent.paused
        question = paused.input_request if paused is not None else None
        pending = paused.request if paused is not None and question is None else None
        return (list(self.chat), status) + flow_outputs("", pending, question)[2:]

    async def gui_chat_send(self, text: str):
        """Send the user's message and run the turn until it finishes or needs the user."""
        if not text.strip():
            return self._chat_outputs(status="Type a message first.")
        if self.agent.paused is None:
            self.chat.append({"role": "user", "content": text})
        return self._chat_outputs(await self.agent.send(text))

    async def gui_chat_approve(self):
        """Approve the call the turn is paused on."""
        try:
            return self._chat_outputs(await self.agent.approve())
        except (KeyError, RuntimeError):
            return self._chat_outputs(status="⚠ That request is not pending any more "
                                             "(answered elsewhere?). Start a new chat to go on.")

    async def gui_chat_reject(self):
        """Reject the call the turn is paused on."""
        try:
            return self._chat_outputs(await self.agent.reject())
        except (KeyError, RuntimeError):
            return self._chat_outputs(status="⚠ That request is not pending any more "
                                             "(answered elsewhere?). Start a new chat to go on.")

    async def gui_chat_answer(self, _input_id: str, action: str, content: dict | None = None):
        """Answer the server's question (shown to the user only)."""
        try:
            return self._chat_outputs(await self.agent.answer(action, content))
        except InputInvalid as e:
            return (gr.skip(),) * 9 + ("⚠ " + "  \n⚠ ".join(e.errors),)
        except RuntimeError:
            return self._chat_outputs(status="⚠ No question is waiting.")

    async def gui_chat_attach(self, uri: str) -> str:
        """Read a resource the user chose; it goes with their next message."""
        try:
            attached = await self.agent.attach_resource(uri.strip())
        except (MCPError, OSError, ValueError) as e:
            return f"⚠ Not attached: {server_text(str(e))}"
        return f"Attached {server_text(uri.strip())} ({len(attached)} characters); it goes " \
               "with your next message."

    async def gui_load_prompts(self):
        """The server's prompts, for the prompt picker."""
        try:
            prompts = await self.list_prompts()
        except (MCPError, OSError):
            return gr.update(choices=[])
        self._prompts = {prompt.name: prompt for prompt in prompts}
        return gr.update(choices=list(self._prompts))

    def gui_prompt_template(self, name: str) -> str:
        """An arguments template from the prompt's declared arguments."""
        prompt = getattr(self, "_prompts", {}).get(name)
        names = [argument.name for argument in (prompt.arguments or [])] if prompt else []
        return "{" + ", ".join(f'"{n}": ""' for n in names) + "}"

    async def gui_chat_prompt(self, name: str, arguments_json: str):
        """Use a server prompt: its messages join the conversation and the model replies."""
        try:
            arguments = parse_arguments(arguments_json)
        except ValueError as e:
            return self._chat_outputs(status=f"⚠ Prompt arguments: {e}")
        self.chat.append({"role": "user", "content": f"(server prompt `{name}` {arguments_json})"})
        try:
            return self._chat_outputs(await self.agent.use_prompt(name, arguments))
        except (MCPError, OSError) as e:
            return self._chat_outputs(status=f"⚠ {server_text(str(e))}")

    async def gui_chat_new(self):
        """Clear the conversation; anything pending is rejected or cancelled (audited)."""
        await self.agent.new_chat()
        self.chat = []
        return self._chat_outputs(status="New chat.")

    def _build_chat_tab(self, interface: gr.Blocks):
        """The Chat tab: a model calls the server's tools through this client."""
        gr.Markdown("### Chat with a model that calls the server's tools through this client")
        gr.Markdown(f"Model: `{self.model.name}`. Every tool call it makes meets the policy on "
                    "the Permissions tab, waits here for your approval when the policy is "
                    "*ask*, and is in the Audit tab with source `model`. Questions from the "
                    "server come to you, never to the model. **Baseline:** no LLM-specific "
                    "defences yet.")
        chatbot = gr.Chatbot(label="Conversation", height=420)
        status = gr.Markdown()
        message = gr.Textbox(label="Message", lines=2)
        send_btn = gr.Button("Send", variant="primary")
        with gr.Group(visible=False) as approval_group:
```
